# Text posted under the user's name

How a skill shows a comment, reply or review summary before it goes public.
Pointed at, never copied.

The user is approving text that lands publicly under their name, so show it
twice and wait for their answer:

- Rendered, so it reads at the chat's width. Keep the body's own paragraph and
  bullet breaks, and render it as plain paragraphs rather than a blockquote:
  the chat collapses the blank lines inside a `>` block, which loses those
  breaks.
- Then verbatim, in a fenced block to copy from. A fenced block alone doesn't
  wrap, so a long line is unreadable without the rendered copy above it.

Write it in a neutral register, since it describes someone's work to their
face: no praise or thanks preamble, no hedging, no narrating the diff back.
