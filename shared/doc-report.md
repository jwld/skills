# Doc report

The report after a pass over agent docs, comments or ADRs. Pointed at, never
copied. Succinct, as [succinct.md](succinct.md) sets out.

- Group by file. For each, say whether it was wrong, missing, misplaced,
  overlong, or no longer needed.
- Quote the wording that landed, so it can be judged without opening the file.
- Order by consequence, and separate what actively misled (a false claim, a
  stale rule) from what only ran long or was merely nice to record.
- Where a doc and the environment disagreed, name which one moved.
- Say so when nothing needed changing. That's a normal outcome, not a failed
  search.
